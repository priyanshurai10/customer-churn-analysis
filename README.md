# Customer Churn Analysis Project

Hi, this is my final project for the BharatCares / IBM SkillsBuild internship. 

In this project, I made a Customer Churn Analysis dashboard. The goal is to understand why customers leave a company and to predict which ones are at risk so the business can take action.

### Dataset Used
I am generating a dummy dataset inside the code itself using numpy so the app can run easily without needing to upload a CSV file every time. But the logic is based on the popular Telco Customer Churn dataset from Kaggle.
Dataset link: [Kaggle Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

### How to run my project
1. First, install all the required libraries:
   `pip install -r requirements.txt`

2. Run the streamlit app:
   `streamlit run app.py`

3. The dashboard will open in your browser automatically.

### Files in this repo:
- `app.py`: The main python code with backend ML and frontend UI.
- `requirements.txt`: List of modules needed to run the code.
- `Project_Report.md`: A detailed report on what I found out and what the business should do.
- `README.md`: Project overview (this file).
